Handoff 01 · App shell · read-back

What I understood

Pick a direction below (or a mix). I'll then go deep on it: every state, light + dark, dialogs, tokens, icon.
The product
A Mac app that starts, watches and stops dev commands. A project is a grouping of commands across repos, not a folder. Sidebar of projects › groups › commands, one real PTY pane (it must host claude, vim, htop), a vitals footer.
The ask
Swap system chrome for designed chrome: sidebar surface, row anatomy, a pane header replacing the toolbar strip, a footer with hierarchy, custom dialogs, tokens, an app icon. Dark-first, light first-class. Native behaviour, not native look.
Fixed points
IA, the six states and their meanings, ✓ for exit 0, backoff countdown, restart-to-apply, ⌘ shortcuts, drop-to-add, VS Code / Finder hand-offs. SwiftUI/AppKit + SwiftTerm, no web views. No splits, sheets or menu-bar extra.
Shared across all three directions — the status language
Stopped
Hollow ring. Calm, no colour.
Starting
Amber arc that spins. Motion, not just yellow.
Running
Solid green with a soft halo; slow breathe.
Done · exit 0
Check in a ring. Distinct from stopped by shape.
Crashed · backoff
Red core; outer ring drains as "restarting in 16 s" counts down.
Error
Orange triangle. Start disabled; reason in header.
Each state differs by shape as well as colour, so it reads at a glance and for colour-blind users. Glyph grows from 9 pt to 12 pt on a 14 pt hit area. Restart-to-apply stays a small ↻ badge after the name, upgraded to an accent chip in the pane header.
Structural moves (all directions)
The unified toolbar becomes a slim titlebar; the pane gets its own header (identity · status chip · folder · Stop/Restart · ⋯). Footer drops identity and keeps vitals. Groups collapse to one line with a count ("Backend · 4 · 1 running"). Rows reserve the action slot so nothing jumps on hover.
Assumptions to confirm
Type stays SF Pro / SF Mono in the app (Geist stands in on the canvas). One accent colour for selection and links, separate from status hues. Dialogs become custom sheets presented by AppKit. Window title still set for Mission Control even when hidden.
