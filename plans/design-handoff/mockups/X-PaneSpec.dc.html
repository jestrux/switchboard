Primary action by state. Running / starting: Stop. Crashed: Start now (accent-tinted) plus Stop, which cancels the pending restart. Done / never run: Start. Error: Start, disabled, with the reason as its tooltip.
Footer. Full: folder · pid · uptime, or exit · ran for finished runs. Mid drops the folder. Min drops the footer; the bar's tooltip carries the vitals. Backoff is a 2 pt red bar under the header that drains.
Focus. Focused: accent rule, raised bar, full-contrast text, filled cursor. Unfocused: flat bar, secondary text; terminal text is never dimmed. Hover: the bar lifts so actions read as buttons.
